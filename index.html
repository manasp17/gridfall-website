About GRIDFALL

GRIDFALL is a single-level tactical JRPG experience built for a capstone project, combining movement strategy, automated battle phases, and persistent progression.

A story-first JRPG feel

This project focuses on classic JRPG systems: movement points, grid-based engagement, auto-resolved combat, and character leveling. Players advance through phases and save progress while exploring the first level.

Built as a team

It is a team-built Godot project using C# classes, authored by a student capstone group. This landing page is a personal website built to showcase the game, the build process, and the development roles.

How to download and run GRIDFALL

Follow these steps to set up Godot, import the project, and start playing your first demo level.

1. Install Godot

Download the latest Godot Mono build from godotengine.org. Use the .NET-compatible version for this project.

2. Install .NET SDK

Download the .NET SDK from dotnet.microsoft.com. The project uses C# scripts, so this step is required.

3. Import the project

Open Godot, select Import, choose project.godot, and import the repository folder. Accept any version mismatch prompt if needed.

4. Configure globals

Open Project > Project Settings > Globals. Set the autoload script to res://src/Services/GameManager.cs and enable the global variable.

Gameplay systems

GRIDFALL currently includes movement, combat phases, leveling, enemy AI, and save persistence.

Movement phase

Use movement points to navigate tiles. Press Next phase or deplete points to progress to combat.

Battle phases

Automatic combat resolves outcomes based on unit stats. Both player and enemy battle phases play out in sequence.

Progression & saving

Gain experience, level up, and preserve stats across sessions with save/load integration from the pause menu.

Enemy AI

Enemies move and make decisions based on proximity and available actions, creating emergent tactical moments.
